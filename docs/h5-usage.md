# H5 使用指南

浏览器通过 `http://服务器IP` 访问，手机和电脑共用同一套接口与数据。手机底部显示当前角色可用的主导航。

## 管理员配置

进入「基础设置」维护长期配置；每次排班在「安排排班」中完成。基础设置分为三个标签：

| 标签 | 可配置内容 |
|---|---|
| 工作类型 | 新增、编辑、停用工作；说明、颜色、排序；开放工作日、默认每班人数；是否区分主副负责人；长期固定人员 |
| 班次时间 | 班次名称、开始和结束时间、班次顺序及启停 |
| 账号管理 | 管理员可创建、编辑员工账号和重置密码；超级管理员可管理管理员和员工 |

演示种子中的工作只供测试；从零使用时，由管理员自行添加。停用的工作和班次不进入后续生成。

例如某项工作只在周日需要：在工作类型中只勾选「周日」，填写默认人数；新建周期时勾选该工作和所需班次，再在「安排排班 → 确认需求」核对人数；已有周期可点击「重新按默认规则填充」。非周日为 0 且不可填正数，周日仍可按班次调整人数。批量填充会覆盖该周期原有的手工人数，执行前会提示。

周期按所选开始日期计算，首尾都包含在内。双月为连续两个月，季度为三个月，半年为六个月；月末不足时取该月最后一天。最长 366 天，包含闰年情况。编辑已有周期时不能移除已配置班次所在的日期。

## 长期固定名单与动态调配

在工作类型的「长期固定人员」中，每条选择星期、班次、员工和岗位角色。例如周一添加 A，周二分别添加 B、C；同一天可有多条。配置长期生效，各周期无需重新报名。到需求人数应用规则后，每个班次至少覆盖该星期的固定人数，仍可手动修改总人数。

生成时先安排固定人员，并保护他们不被公平优化挪走；仅固定报名的员工不会被自动安排到其他星期或班次。普通提交报名仍可额外参与其他日期。有固定安排的员工可以不勾选额外工作，只提交本周期请假、可用时间和班次上限。未提交的个人草稿不会影响固定安排。

如果请假、上限、人员停用或人数配置使固定名单无法落实，生成结果会明确提示并阻止发布。管理员在「手工调配草稿」中选择日期、班次和工作，替换、移除或补充人员，处理本次例外；操作不改变长期名单。手工调配仍检查资格、时间与人数约束，只修改当前草稿，发布后才生效。重新生成会覆盖手工调配。

已发布排班可以通过「直接调整已发布排班」转交或交换班次。检查具体日期、工作、原人员和接班人后确认，立即生效，无需员工操作。接班人仍需具备普通或长期报名对应的工作／主副资格，并满足请假和班次上限。操作留下管理员审计记录；固定名单继续用于后续周期。

## 账号与权限

「基础设置 → 账号管理」可直接创建账号，设置登录账号（工号）、姓名、手机号、初始密码；已有账号可编辑资料、启停或重置密码。登录账号为 2–32 位字母、数字、下划线或短横线，忽略大小写判断重复；密码为 6–128 位。

普通管理员只管理员工，不能修改管理员、超级管理员或将员工提权。超级管理员可创建、配置管理员和员工。超级管理员自身保留管理入口，不允许降级或停用。密码单向加密保存，无法查看原密码。账号、状态、角色变化或密码重置会吊销该账号会话，需重新登录；保存自己账号后会回到登录页。

旧库升级时，将最早创建的启用管理员升级为超级管理员；其他管理员保留原角色，已有员工和排班保留。新演示库的 `admin` 是超级管理员。生产新库首次创建账号时需使用 `super_admin` 角色。

## 管理员也可参与排班

管理员和超级管理员同时拥有管理权限与个人报名入口。底部「我的报名」用于提交自己的工作意愿、主副角色、可用时间和个人上限；「我的换班」用于处理自己的已发布安排。报名后与普通员工一样参与生成、按人员排班表与公平度统计；未报名也未加入固定名单的账号不会自动被安排。

长期固定名单可选所有启用账号，包括管理员与超级管理员。资格、请假、可用时间及班次上限不因管理身份而豁免；停用账号退出有效候选。员工晋升为管理员后保留原有报名资格。账号管理仍按原层级控制，普通管理员仍只能管理员工账号。

## 员工报名与主副负责人

进入「我的报名」，选择开放报名、排班中或已发布的周期，勾选工作和意愿优先级。需要主副的工作必须明确选择主负责人、副负责人或主副皆可。选择可用时段，必要时标记整日不可用并填写原因；长周期按月查看，所有月份会一起保存。

已发布周期也支持本人报名、修改报名和管理员代报名。正式提交会自动补入从今天起 7 天内的合适空位，不移动已有人员；取消已提交的工作，则移除本周期明天起该工作的安排，保留今天和历史，并撤回受影响的待确认换班。「保存草稿」不执行补位或移除。超过 7 天的新安排可由管理员调配或重新生成发布；已有草稿遇到报名变更时须重新生成，归档周期停止报名。

「保存草稿」不会进入排班候选；「提交报名」后参与额外排班；长期固定报名自动参与。个人班次上限留空表示不限，0 表示本周期不接班。

需要主副的班次，总需求可以是 0 或至少 2 人。生成时先安排主、副各一个必需名额，再按报名角色安排额外名额。一个人不能同时占同班次的主副两个岗位；缺少合格的主或副时会标出缺口，禁止发布。

升级会保留旧用户、报名和已发布排班。旧报名保持普通成员资格，不会自动授予主副资格；开启主副后需要员工明确更新报名。

## 安排排班：连续完成四步

打开底部的「安排排班」，顶部可以切换当前周期，也可以点击「新建排班」。新建时隐藏旧周期选择、刷新、步骤导航和旧周期设置，只显示创建表单与取消入口；取消会回到原周期。周期、需求、人员、草稿和发布都在这一页中完成，不需要在多个后台页面之间寻找入口。

1. **设置周期**：填写名称和起止时间（支持一周到一年），明确勾选本次工作、班次（默认均不选，至少各一项），点击「创建并确认需求」。排班规则可展开调整。系统在同一事务中保存本次选择，只生成所选班次的日期安排，并只按所选工作的开放工作日、默认人数与固定名单填入需求；创建成功后直接进入第二步。基础设置缺少工作或班次时，会提供对应设置入口；初始化失败不会留下半成品周期。
2. **确认需求**：先看本周期总天数、班次数和需求人次，再逐日、逐班次调整人数。默认带入的数字仍需管理员核对。点击「保存需求，下一步」进入人员确认；未改动数字也可直接继续。需求均为 0 或主副人数不合法时，会在当前步骤提示。手机默认优先显示有需求的工作。
3. **参与人员**：查看匹配实际需求的固定人员和本期报名人员。点击「代报名」，直接选择人员、工作和主副角色并提交，无需本人登录；固定名单自动参与。也可展开「固定名单 / 本人报名」开放本人报名。未找到匹配人员时不能生成。
4. **生成发布**：点击「生成草稿」，检查每个日期的人员和主副资格，必要时手工调配。再点击「检查并发布这份草稿」，核对新增、移出、保留的安排及缺口后发布。生成不会改变员工当前看到的生效版本。

本次工作与班次选择会长期保存在该周期；需求表、员工报名、重新填充、初始化和生成发布都遵守此范围，基础设置后来增加的项目不会自动加入。旧周期保留全部启用项的原有行为。已有空周期会自动停在需求步骤，提供「按基础设置初始化需求」。再次初始化只为新增日期／班次填入默认规则，保留已有班次的手工人数及明确的 0；「重新按默认规则填充」会覆盖手工人数，因此会先确认。未保存人数就切换步骤或周期时会提示，取消后保留修改。周期启停／归档操作放在「设置周期 → 当前周期设置 → 更多周期操作」中。

生成按钮上方会显示缺少的准备项及可直接操作的入口。准备检查使用实际启用的工作、班次和工作日，并只计入匹配本期需求的普通或长期报名，不把其他工作的报名视为已就绪。完整的时间、请假、上限和主副覆盖仍在生成与发布时校验。生成后需求、报名或有效配置发生变化时，需要重新生成草稿。

算法为启发式，不能保证所有存在可行解的情况都排满。普通人数缺口会保留显示，主副必需名额的缺口会阻止发布。

## 日表、月历与换班

「排班表」默认打开「我的近期安排」，展示从今天起 7 天的本人已发布安排，可切换 30 天或自定义日期（最多 366 天），跨周期汇总。每项包含日期、工作、班次时间、本人角色与同一天同班次同工作的其他已排人员；人员变更按当前生效版本显示。管理员、超级管理员也使用自己的近期安排。选择矩阵、日表或月历时，可切换周期。管理员可看按人员日表、筛选单个员工，或切换月历；员工月历默认只看自己，也可查看全部员工。

点击月历日期打开当天安排。手机使用底部弹窗，桌面使用居中弹窗；内容包含人员、工作、班次时间和主副角色，无排班也会明确提示。关闭后保留原月份和选中日期。

「我的换班」可选择自己已发布的班次，发起转班或互换，查看待确认和我发起的申请，进行同意、拒绝或撤回。换班保留岗位角色，接班人必须具备对应的报名资格；确认时会再次校验冲突。管理员仍可查看本周期换班记录。

## 周期删除与恢复

管理员和超级管理员在「安排排班」顶部，点击「当前排班周期」右侧的「删除本周期」。操作前显示周期名称与影响范围，确认后移入回收站。删除后该周期从下拉选择、排班表、近期安排、统计及换班待办中隐藏，旧链接不能修改。

只有超级管理员能在「当前排班周期」右侧打开「回收站」，查看删除者、时间及原状态，并恢复周期；即使所有周期均已删除，新建表单上方仍有回收站入口。恢复保留原报名、需求、工作班次范围、草稿、生效版本及换班记录；原已发布排班重新生效，未结束换班恢复待办。删除和恢复均记录实际操作者。

## 页面说明

流程、规则等说明收拢到标题旁的 ⓘ，点击打开说明弹窗；关键缺口、错误和发布后果保留在操作位置。说明图标与标题同排居中，手机可用底部弹窗查看。代报名只更新所选工作和角色，保留原有请假、可用时间、个人上限与备注；已有草稿须重新生成。

## 兼任与固定搭档轮值

有空位时，生成会在优先分散安排后尝试同班次兼任不同工作，已发布周期报名补位也支持兼任。同一天同班次只计 1 班，用于每日、每周和个人上限；工作人次仍分别计数。不能重复占用同一工作的名额，也不能一人兼任同一工作的主副。

管理员进入「基础设置 → 工作类型」，展开工作、开启「区分主副负责人」，在「固定搭档轮值」逐组选择主、副并保存。可同时配置 A主+B副、C主+D副、A主+D副；名单留空不限制组合。搭档名单长期保留，但两人仍须有本期报名或长期固定报名，管理员可以代报。生成先整组选择可用搭档；额外人数也须有允许的搭档在场，不强制各组次数完全相同。任一人请假、超限或无资格则跳过该组；缺口说明提示检查搭档。修改名单不直接改动生效安排，旧草稿须重生。

手工调整草稿时，可先移除原组再添加新组；不匹配的主副组合不能保存或发布。直接换班也检查搭配。新报名遇到双方皆空的近 7 天岗位时，只在两人均可安排时一起补入；已有人员不会被替换。取消某人工作报名仍只移除该人明天起的安排，留下缺口供补位。
