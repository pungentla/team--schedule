# 待办事项

工作台的“待办事项”卡片展示与本人有关的一个未完成待办。优先展示逾期事项，然后按截止时间排序，无截止时间的排在后面。同一截止时间优先展示紧急事项。“更多待办”进入列表，支持与我有关/公开待办/仅自己可见、状态、标签和文字筛选。私密待办卡片使用淡紫色背景区分。

## 内容和权限

- 标题必填，最多80字；描述选填，最多4000字。截止时间选填。
- 默认全员可见。自己执行的待办可设置“仅自己可见”，其他成员、管理员和超级管理员均不能通过平台读取，包括详情、列表、标签和提醒。
- 管理员可以分配给一个启用的员工或管理员。分配给他人的待办须保持公开。超级管理员通过名字菜单的“待办管理”进入，可分配给员工。
- 创建者修改内容或删除。主执行人标记完成，无需管理员审核，可填写1000字以内的完成备注，或恢复为未完成。
- 一个待办最多8个标签，每个最多20字，可自由输入或选择本人可见的已有标签。
- 优先级支持普通和紧急。最多30个子任务，每项最多120字。管理员可为每个子任务分配不同的执行人，未指定时跟随主执行人。
- 分配给他人的子任务要求主待办公开。各执行人只勾选自己负责的子任务；所有子任务完成后，主执行人才能确认整个待办完成。已完成待办要新增子任务时须先恢复为未完成。
- 子任务分配后会进入对应员工的“与我有关”和工作台待办，也会收到分配通知，并可自行设置提醒。移除其全部执行职责后，会清理其提醒及未读通知。
- 逾期仍可完成，卡片显示“逾期完成”。逾期未完成的待办也可由创建者或主执行人归档，从工作台和未完成列表移出，暂停本条提醒；“已归档”筛选可查看和恢复。归档不影响后续重复，恢复本条后需重新设置提醒。

## 提醒

新建时可为主执行人设置一次提醒：截止时、提前1小时、提前1天或自定义时间。自定义时间不依赖截止时间。创建者、主执行人、子任务执行人之后各自维护自己的提醒，互不覆盖。

分配消息和到时提醒进入站内铃铛，点击打开对应待办并清除该待办的未读消息。已授权的设备通过既有 Web Push 通道接收通知；“消息提醒”中的待办推送开关默认开启，关闭不影响站内消息。设备推送仍受设备授权和已有推送服务连通性限制。

服务启动后及运行期间每5秒检查到时提醒，使用数据库记录防止重复。完成或删除会清理待发送的设备推送；完成后不再产生到时提醒。推送正文不包含待办标题或描述，详情仅在登录后读取。

## 重复

支持每周和每月重复，须填写截止时间。到达截止时间后自动生成下一个未来周期，不要求上一条已完成，避免未完成事项阻断后续工作。服务中断跨过多个周期时只生成下一个未来周期，不补建所有错过的历史事项。

重复日期按北京时间计算；每月保留首次设置的日号，如1月31日、2月28日、3月31日。子任务的内容及执行人会复制、勾选状态清空，提醒按相对截止时间的间隔延续。

修改仅影响所选待办，下一次自动生成时沿用该条内容，已经生成的其他待办需单独修改。选择“不重复”或删除某一期，会停止整组继续自动生成；已经生成的其他待办保留。
