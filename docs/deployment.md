# 小程序上线配置指南

当前 AppID：`wx2503b1cfbc7a04a0`

本文覆盖从"本地能跑"到"真机能用 → 能提审"的完整配置链路。

如果只需部署后端并通过浏览器访问，默认已支持 `http://服务器IP`，无需域名或证书，见 [IP 部署指南](production-setup.md)。下面的 HTTPS 合法域名配置针对微信小程序正式版。

## 一、开发者工具打开项目

1. 微信开发者工具 → 导入项目
2. 目录选到 `miniprogram/`（**注意：是 `miniprogram` 目录，不是仓库根目录**）
3. AppID 会自动读取 `project.config.json` 里的 `wx2503b1cfbc7a04a0`
4. 基础库版本建议 ≥ `3.5.5`（`project.config.json` 已配置）

### 第一次打开必做的设置

**详情 → 本地设置 → 勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**

> 不勾这个，`http://127.0.0.1:3000` 的请求会被直接拦截，登录会失败。
> 这个开关只影响开发者工具，不影响真机。

## 三、真机预览/调试

真机上 `127.0.0.1` 指的是**手机自己**，必然连不上电脑。必须用电脑的局域网 IP。

### 步骤

1. **确认手机和电脑连同一个 WiFi**（这是最常见的失败原因）
2. **看后端启动日志**，会打印：

```
本机访问:   http://127.0.0.1:3000/api/health
局域网访问: http://192.168.1.5:3000/api   (真机调试用这个)
```

3. 在小程序登录页，点顶部地址栏的「切换」，填入 `192.168.1.5:3000`（只填 IP:端口即可，会自动补 `http://`）
4. 点「保存并测试连接」，会先探活，通了才保存

> 登录页也有**「自动探测局域网」**按钮，会在常见网段（192.168.1.x / 192.168.0.x / 10.0.0.x 等）扫描 3000 端口。
> 但如果你的网段不常见，或路由器开了 AP 隔离，扫描会失败——这时**手填日志里的地址最可靠**。

### 连不上时的排查顺序

| 现象 | 原因 | 解决 |
|---|---|---|
| 提示「连不上 …/api/health」 | 后端没启动 | `cd backend && npm run dev` |
| 同上 | 手机与电脑不同 WiFi | 连同一个 WiFi；关掉手机流量 |
| 同上 | 网段填错 | 用启动日志里的地址，别猜 |
| 同上 | 电脑防火墙拦截 3000 端口 | Windows 防火墙放行 Node.js；macOS 允许传入连接 |
| 同上 | 路由器开了「AP 隔离」 | 关掉该设置，或用手机热点（电脑连手机热点） |
| 真机预览时白屏 | 未开「不校验合法域名」 | 真机调试模式下同样需要开启（真机调试面板里设置） |

## 四、正式版必须完成的配置

### 4.1 后端必须是 HTTPS + 已备案域名

小程序**正式版**（`envVersion === 'release'`）强制要求：

- 协议必须是 **HTTPS**
- 域名必须完成 **ICP 备案**
- 必须在小程序后台配置**服务器域名白名单**

本地 `http://192.168.x.x` **只能在开发版/体验版**通过"不校验合法域名"使用，正式版一律不行。

### 4.2 配置合法域名

小程序管理后台 → **开发 → 开发管理 → 开发设置 → 服务器域名**

| 类型 | 需填写 |
|---|---|
| request 合法域名 | `https://你的域名` |

> 本项目只用 `wx.request`，不涉及 `uploadFile` / `downloadFile` / `socket`，所以**只需配 request 一项**。

### 4.3 填写线上地址

改 `miniprogram/config/env.js`：

```js
const PROD_URL = 'https://your-domain.com';   // 不要带 /api 后缀
```

保存后，正式版（release）会自动走 `PROD_URL`，开发版/体验版仍走本机或局域网。

### 4.4 后端部署要点

| 项目 | 要求 |
|---|---|
| Node 版本 | ≥ 22.5.0（依赖内置 `node:sqlite`） |
| 环境变量 | `PORT`、`HOST=0.0.0.0`、`TZ=Asia/Shanghai`、`DB_FILE` |
| 数据库文件 | 需持久化磁盘（SQLite 是文件数据库，容器部署要挂卷） |
| 反向代理 | Nginx/Caddy 做 TLS 终止，转发到 `127.0.0.1:3000` |
| CORS | 后端已开全局 CORS，小程序不受同源限制，无需额外配置 |

**Nginx 参考配置**：

```nginx
server {
    listen 443 ssl http2;
    server_name your-domain.com;

    ssl_certificate     /path/to/fullchain.pem;
    ssl_certificate_key /path/to/privkey.pem;

    location /api/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Request-Id $request_id;
    }
}
```

> `X-Request-Id` 会被后端记录到审计日志的 `request_id` 字段，便于排查问题。

### 4.5 生产环境必改项

| 位置 | 默认值 | 必须改 |
|---|---|---|
| `backend/.env` | `SESSION_TTL_DAYS=30` | 视安全要求调整 |
| 种子数据 | `admin/123456`、`emp001~020/123456` | **上线前务必重置所有员工密码** |
| `backend/.env` | `SCHEDULE_SEED=42` | 可保留（保证排班可复现），也可每次随机 |
| 数据库 | 开发库含演示数据 | 生产库执行 `npm run migrate` 建空表，**不要跑 seed** |

## 五、提审前检查清单

### 5.1 功能与配置

- [ ] 后端 HTTPS 可访问，`/api/health` 返回 200
- [ ] 后台已配置 request 合法域名，且与 `PROD_URL` 一致
- [ ] `PROD_URL` 已填写，正式版登录能连通
- [ ] 所有演示账号密码已重置为强密码
- [ ] 生产库无演示数据

### 5.2 审核合规（重要）

本项目**不收集用户隐私信息**，这是最大的有利条件：

- 没有用 `wx.login` / `wx.getUserProfile` / `getPhoneNumber` / 位置 / 相册
- 登录方式是自建工号 + 密码，不走微信授权
- 因此**无需**配置「用户隐私保护指引」，也无需隐私弹窗

但仍需注意：

| 检查项 | 说明 |
|---|---|
| 服务类目 | 选择「工具 → 效率」或「企业内部管理」类目。<br>若以"企业内部使用"定位，可选择**不发布到公开搜索** |
| 页面内容 | 确保没有测试数据残留（如"测试""demo"字样） |
| 功能完整性 | 审核员会用真实账号走一遍，确保登录、看排班、发起换班都能走通 |
| 测试账号 | 提审时在"版本描述"里**提供可登录的测试账号和密码**，否则审核员进不去会驳回 |

> ⚠️ 关于类目：本项目是**团队内部排班工具**，不涉及支付、虚拟商品、直播、医疗、金融等敏感类目，审核风险低。但**类目选择以小程序后台最新选项为准**，以官方审核规范为准。

### 5.3 常见驳回原因与对策

| 驳回意见 | 原因 | 对策 |
|---|---|---|
| "页面无法打开/白屏" | 合法域名未配或 HTTPS 不可用 | 检查 4.1、4.2 |
| "服务不可用" | 后端未启动或域名解析失败 | 用手机流量访问 `/api/health` 验证 |
| "功能不完整" | 审核员没账号，进不去 | 版本描述里提供测试账号 |
| "类目与实际功能不符" | 类目选错 | 按实际用途重选 |
| "涉及…需提供资质" | 类目误选到需资质项 | 改选工具/效率类 |

## 六、发布流程

```
开发版（develop）
   ↓ 上传代码
体验版（trial）  ← 扫码体验，用真实手机验证
   ↓ 提交审核
审核中
   ↓ 审核通过
正式版（release）← 手动"发布"才生效
```

**注意**：审核通过后**不会自动上线**，需要在后台点「发布」。

### 版本管理建议

| 环境 | envVersion | 服务器地址来源 |
|---|---|---|
| 开发者工具 | `develop` | `DEV_URL`（127.0.0.1） |
| 真机调试 | `develop` | 手动设置的局域网地址 |
| 体验版 | `trial` | 手动设置的局域网/测试服地址 |
| 正式版 | `release` | `PROD_URL` |

代码里已按 `envVersion` 自动分流，无需手动切换。
